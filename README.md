# FilmVist — релизы

Официальные сборки FilmVist для Windows и Android публикуются во вкладке **Releases** этого репозитория.
Приложение проверяет обновления здесь (`releases/latest`).

`open.html` — страница, которая открывает ссылки «Поделиться» в приложении FilmVist
(`https://magver.github.io/FilmVist-Releases/open.html?animeId=…`).
